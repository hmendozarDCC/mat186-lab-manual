Executive Response to Departmental Review

1. Data Privacy and PII Protection

To address concerns regarding “Public” repositories on GitHub:

  • PII Safeguards: Students use GitHub solely as a hosting platform for professional code portfolios. No Personal Identifiable Information (PII)—such as student IDs, home addresses, or personal phone numbers—is permitted in public code.
  • Secure Grading Workflow: While the code is public, the final graded assessment is submitted as a Private .zip file to Brightspace. This ensures student intellectual property and grades remain strictly within the college’s secure LMS.

2. Rigor and Credit-Hour Equivalence

These labs represent the Computer Component of a 4-credit course, requiring significant work outside of class (approx. 2 hours per credit hour).

  • Scaffolded Independence: Early labs provide syntax guidance. Modules 10–15 shift to Inquiry-Based Learning, where students must determine appropriate statistical tests and write code without templates.
  • Synthesis: Each lab requires the raw code (.qmd), the rendered report (.html), and a written statistical interpretation.

3. Textbook Alignment

This manual confirms alignment with the required texts in the Spring 2025 EXO: 1. Statistics: Introduction Using R (Crawley, 2nd ed., 2015) 2. A Student’s Guide to R (Horton, Pruim, & Kaplan, 2015)

The OER modernizes these resources by replacing 2015-era syntax with contemporary Tidyverse workflows.

Specific Advanced Content

  • Non-Parametric Tests: Week 13 explicitly teaches Wilcoxon Rank-Sum and Signed-Rank tests. Students must determine through normality checks whether a Parametric or Non-Parametric test is justified.
  • ANOVA & Post-Hoc: Week 12 covers One-Way ANOVA followed by Tukey’s HSD to identify specific group differences.

Grading & Instructor Workflow

  • LMS Hub: Instructors link the GitHub site in Brightspace. Work is collected via Brightspace Assignment Folders (.zip files).
  • Standard Rubric (10 pts):
    • Structure (2 pts): .zip method and .Rproj use.
    • Accuracy (4 pts): Code execution and output.
    • Interpretation (4 pts): Statistical explanation of results.
