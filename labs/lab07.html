Lab 7: Cleaning Data with dplyr

Learning Objectives

  • Understand the concept of “Data Wrangling.”
  • Use the Pipe Operator (|>) to chain commands.
  • Learn core cleaning functions: filter(), select(), and rename().
  • Handle missing values (NA).

Introduction

“Raw” data is rarely ready for analysis. It might have columns you don’t need, rows that aren’t relevant to your study, or names that are hard to type. In this lab, we move from simply looking at data to transforming it. Raw data from portals like NY Open Data often contains too many variables or messy formatting. we use the dplyr package (part of the tidyverse) to “tidy up” our datasets and to keep only what is relevant to our research question.

Part 1: The Pipe Operator (|>)

Think of the pipe operator as saying the words “and then.” It takes the output of one function and passes it to the next.

Instead of writing: clean_data <- filter(raw_data, age > 18)

We write: clean_data <- raw_data |> filter(age > 18)

Part 2: Core Cleaning Functions

1. select() - Picking Columns

If your dataset has 100 columns but you only need 3, use select().

library(tidyverse)

# Keep only the 'name' and 'height' columns
sw_small <- starwars |> 
  select(name, height)

# Use knitr::kable to generate an accessible HTML table
knitr::kable(head(sw_small))

2. filter() - Picking Rows

If you only want to look at specific observations (e.g., characters taller than 100cm).

library(tidyverse)

# Keep only rows where height is greater than 100
tall_characters <- starwars |> 
  filter(height > 100) |>
  select(name, height, species, homeworld) # Selecting specific columns makes tables easier to read

# Use kable to create an accessible HTML table structure
knitr::kable(head(tall_characters))

3. rename() - Changing Names

If a column name is confusing or has spaces, rename it.

library(tidyverse)

# Change 'homeworld' to 'home_planet'
sw_clean <- starwars |> 
  rename(home_planet = homeworld)

# We select a few columns so the table isn't too wide for a screen reader
knitr::kable(head(sw_clean[, c("name", "height", "home_planet")]))

Part 3: Handling Missing Data (NA)

In R, missing values are represented as NA (Not Available). You can’t calculate the mean of a column if it has NA values without telling R what to do.

To remove rows with any missing data:

library(tidyverse)

# Remove rows where height is NA
tidy_sw <- starwars |> 
  drop_na(height)

# Display the first six rows using an accessible HTML table format
knitr::kable(head(tidy_sw[, c("name", "height", "mass", "species")]))

The goal of the following tasks is to create a “Clean” version of our table by selecting 4 key columns, filtering for a specific sector, and renaming columns for better readability.

ImportantTask 2: select important columns

Select the 4 most important columns by their position. This avoids “Column not found” errors caused by hidden spaces!

kept Term , Institution Sector, Total Enrollment, and Hispanic/Latino.

cleaned_suny <- ny_data |>select(1, 2, 3, 6)

ImportantTask 3: Rename the columns for clarity:

We shortened the names to semester, sector, total, and hispanic_latino. In general: rename(new_name = old_position_or_name) cleaned_suny <- ny_data |>select(1, 2, 3, 6)|> rename(semester = 1, sector = 2, total_enrollment = 3, hispanic_latino = 4)

ImportantTask 4: Filter for a specific category. We narrowed the results to only show “Community Colleges”.

cleaned_suny <- ny_data |>select(1, 2, 3, 6)|> rename(semester = 1, sector = 2, total_enrollment = 3, hispanic_latino = 4)|> filter(sector == "Community Colleges")

Pro-Tip: The “Glimpse”

Always run glimpse(your_data) after cleaning to make sure you haven’t accidentally deleted something you meant to keep!
